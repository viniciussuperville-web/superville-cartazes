# Cartazes SuperVille

Sistema gerador de placas de oferta das lojas SuperVille (Oferta, Clube Fidelidade e Cashback), nos tamanhos A4, A5 (2 por folha) e A6 (4 por folha).

- `index.html`: sistema (login por loja, ofertas, impressão, lotes e administração)
- `exemplos.html`: exemplos de todas as dinâmicas, para conferência visual
- `data/produtos.json`: base de produtos (código interno, código de barras, descrição, setor)
- `js/placa.js`: cálculos e desenho das placas
- `assets/`: cabeçalhos das artes e logos

Dados (ofertas, lotes, lojas e usuários) ficam no Firebase `superville-cartazes`.
